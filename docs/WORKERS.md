# GARY workers

The versioned inventory is available with `gary profiles --json`. It contains
no credentials. Dynamic account balance, quota, reset and health data remains
outside Git and is reported as `UNKNOWN` or `STALE` when it is not fresh.

The baseline `gpt-5.6-luna` route is the certified default. Native Codex
alternatives, MiMo, OpenCode, and Antigravity are explicit candidate routes.
MiMo is recorded as Xiaomi MiMo through the Responses route with LOW identity
confidence and web search unavailable. OpenCode uses its local auth store;
Antigravity uses its local session. Neither route is silently selected.

GARY chooses capability and certification before economics. A second worker is
allowed only for a genuinely independent task, gets a separate worktree and
base SHA, and is integrated serially.
